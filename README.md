# Форточка

Снег прямо на рабочем столе. Падает поверх всех окон и копится сугробами на их верхних краях, а сдвинешь окно — сугроб осыпается.

![панель](docs/panel.png)

## Что умеет

- **4 сезона** — зима (снег и сугробы), весна (сакура), лето (пух одуванчиков и светлячки), осень (листопад и дождь)
- **Погода как на улице** — вводишь город, и если там идёт снег, он идёт и у тебя на экране. Ветер тоже настоящий. Данные с [open-meteo](https://open-meteo.com), без ключей и регистрации
- **Питомец** — пиксельный кот или лиса гуляет по панели задач, сидит, спит. Можно погладить мышкой
- **Интернет-радио** — станции SomaFM, своя ссылка на поток, таймер сна. Может само подбирать станцию под погоду
- **Звуки природы** — дождь, ветер, камин, сверчки. Генерируются прямо в программе через WebAudio, без единого аудиофайла
- **Обои под погоду** — программа рисует пейзаж под сезон, время суток и погоду и ставит его на рабочий стол. Выключишь — вернутся твои старые обои
- **Цвета под настроение** — окно программы и еле заметная подсветка по краям экрана перекрашиваются в тона неба. Палитры приглушённые, глаза не режет
- Окно не мешает — все клики проходят насквозь

## Запуск

```
npm install
npm start
```

Собрать exe под Windows:

```
npm run dist
```

## Как это работает

Поверх экрана висит прозрачное окно без рамки, которое пропускает мышь (`setIgnoreMouseEvents`). На нём canvas, где рисуются частицы.

Чтобы снег ложился на окна, нужно знать, где они. На Windows это делает маленький кусок C# через PowerShell (`EnumWindows` + `DwmGetWindowAttribute`), раз в 250 мс отдаёт прямоугольники окон в порядке z-order. Так можно понять, какая часть верхнего края окна реально видна, а какая закрыта другим окном.

Сугроб — это просто массив высот по колонкам в 3 пикселя. Снежинка падает в колонку, и если склон получается слишком крутой, снег сползает к соседям. У краёв окна лимит высоты меньше, поэтому сугроб получается закруглённым, а лишнее падает вниз.

Сугроб специально неровный: у каждой колонки своя «вместимость» из плавного шума, поэтому получаются бугры и ямки. Сверху налипают комья, у краёв снег свешивается козырьком, а под толстым сугробом растут сосульки.

Настроение считается из сезона, погоды и времени суток (`src/mood.js`). Из него получаются палитра для окна, цвет подсветки, набор звуков и картинка для обоев (`src/panel/wallpaper.js`, рисуется на canvas с зерном от даты). Обои ставятся через `SystemParametersInfo` на Windows, скрипт plasmashell на KDE и `gsettings` на GNOME. Перед этим программа запоминает, какие обои стояли, и возвращает их при выключении.

На Linux работает через `wmctrl` (только X11). На Wayland окна узнать нельзя, поэтому снег копится только на панели задач.

## Структура

```
src/
  main.js          окна, трей, IPC
  windows.js       позиции чужих окон
  weather.js       open-meteo
  mood.js          настроение: сезон + погода + время суток → цвета
  wallpaper.js     поставить/вернуть обои
  store.js         настройки в json
  overlay/         прозрачный слой: частицы, сугробы, питомец
  panel/           окно настроек
  shared/pets.js   пиксельные спрайты
```
